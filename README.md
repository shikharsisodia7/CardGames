# CardGames

CardGames is a Python terminal-based card game collection. It lets you play multiple classic card games from one menu, including Blackjack, War, Go Fish, Memory Match, Crazy Eights, Rummy, 5-card Poker, and Texas Hold'em.

## Features

- Multiple card games in one Python file
- Standard 52-card deck with suits and ranks
- Player and AI opponent support
- Simple terminal menu
- Game scoring system
- Basic AI decision-making for some games
- Easy to run with no extra libraries

## Games Included

- Blackjack
- War
- Go Fish
- Memory Matching Game
- Crazy Eights
- Rummy
- 5-card Poker
- Texas Hold'em

## How to Run

Make sure Python is installed, then run:

```bash
python CardGames.py
